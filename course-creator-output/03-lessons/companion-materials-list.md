# Companion Materials List

## Learner guide tabs

The files in `course/learner-guide/` are formatted as one main tab and one tab per video. They can be copied into the course Google document without restructuring.

- `Main.md`: course map, prerequisites, workflow, and branch navigation.
- `00-setup.md`: clone, install, verify, and run.
- `01-design.md`: design and use the prototype skill.
- `02-prd.md`: clarify the brief and create the accepted PRD.
- `03-research.md`: compare alternatives and specify contracts.
- `04-slice.md`: create vertical units and optionally preview issue publishing.
- `05-build.md`: implement with RED and GREEN feedback loops.
- `06-review.md`: review against evidence and update documentation.

## Copy-paste prompts

Use the matching file in `course/prompts/` during each live demonstration. The prompts pin the requested skill, inputs, output, and stopping condition so recording results remain predictable.

## Instructor materials

- `course/recording/recording-checklist.md`: repeatable five-minute lesson timing and production checks.
- `course/recording/02-prd-answer-key.md`: prepared answers for the interactive Q&A lesson.
- `course/BRANCHES.md`: snapshot map and commands for publishing course branches.
- `course/END_STATE.md`: final product, artifact, skill, and verification inventory.
